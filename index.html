↗ Rclone Drive Migration
Locally Operated File Migration Utility

Move Google Drive files with care.

Rclone Drive Migration is a locally operated workflow that uses the open-source rclone command-line program to copy selected files and folders between Google Drive accounts.

Important: This website does not connect to Google Drive, request sign-in, or receive your files. The actual migration is initiated and run by the operator on their own computer using rclone.

How it works

1. Authorize accounts

The operator configures separate rclone connections for the source and destination Google accounts through Google's OAuth authorization process.

2. Select folders

The operator chooses a source folder and a destination folder. Files within nested folders can also be copied.

3. Copy files

The workflow uses rclone's copy operation. Original source files are not intentionally deleted.

4. Verify results

Local logs and comparison tools help identify files that may not have copied successfully.

What this utility does not do

This is not a hosted file-transfer service. It does not provide a website upload form, store Drive content on a web server, sell or share Google user data, or use Google Drive data for advertising.

Copying files is not the same as transferring Google Drive ownership. File IDs, sharing permissions, and version histories may not be preserved.
